Skills Showcase Landing Page

A fully responsive event page built entirely through prompts — no HTML written by hand.

What it is

A landing page is a focused web page built around a single action — in this case, registering for a guest talk. The event was Agents That Ship, a session at Atlantis University's School of Technology on what actually breaks when AI agent systems move from a demo to a real production environment.

The talk covered three failure points: orchestration falling apart once one agent becomes many, evaluation going stale as real-world inputs drift away from demo data, and the moment an agent needs to admit it is stuck and hand control back to a human.

What I did

Rather than writing HTML directly, I built the page by writing a sequence of three detailed prompts for Lovable, an AI web builder that converts text descriptions into working code. Each prompt added one complete layer without disturbing what came before.

Prompt 1 — Visual identity and hero

Established the Technology blue color scheme, set the typographic scale, and built the full-viewport hero section with the headline "Agents That Ship," a supporting description, and a primary Register Now button.

Prompt 2 — Speaker and talk

Added a speaker block for Diana Renard (Head of Platform Engineering at Rivet Labs) with a photo placeholder, and a talk section describing the three production failure points, all styled to match the first prompt's design.

Prompt 3 — Logistics and registration

Added a Logistics section (Tuesday 13 October 2026, 6:30–8:00 PM, Campus Auditorium, Doral campus) and a registration form with first name, last name, email, and affiliation. On submit, the form shows an inline confirmation message without reloading the page.

The key skill was writing each prompt precisely enough that the new layer integrated cleanly with everything already on the page.

What came out

A complete, fully responsive web page: a full-screen hero, a speaker and talk block, an event details section, and a working registration form — built without writing a single line of HTML or CSS by hand. The page adjusts correctly on desktop, tablet, and mobile. The registration form shows a confirmation message on submit without navigating away from the page.
