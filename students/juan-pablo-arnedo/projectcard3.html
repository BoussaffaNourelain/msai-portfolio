More Memory

A running memory layer that captures what matters from AI conversations and saves it to Notion so nothing is lost when the chat closes.

What it is

AI conversations are ephemeral by default. When you close a chat, the context disappears — things you explained about yourself, decisions you made, patterns the assistant learned about how you work. The next session starts from zero.

More Memory is a small web page and Claude Code skill that solves this. Anything worth keeping — a preference, a project decision, a lesson learned — gets saved to a structured Notion database instead of disappearing. Future conversations can pick it up by checking the memory at the start of a session.

What I did

I built a local web page as a simple front end for viewing and managing saved memories. Behind it, I configured the Notion MCP server inside Claude Code, which gives the assistant direct write access to a Notion workspace without any manual copy-pasting.

I then wrote the skill instructions that tell the assistant when and how to save something: what counts as worth keeping, how to classify it, and where to file it. Memories are organized into four types:

User Who you are, your role, how you like to work
Project Ongoing work, goals, decisions, deadlines
Feedback What worked, what to avoid, corrections
Reference Where to find things — links, file paths, systems

Each memory is stored with a name, a description, and the full content — enough that a future conversation can understand it without extra context.

What came out

A memory layer that is running and growing. When I ask Claude to remember something during a session, it appears in Notion within seconds, tagged and organized. At the start of the next session, the assistant checks the memory index and picks up where we left off — without me having to re-explain who I am or what I am working on.

The system is used in every Claude Code session and is the reason the assistant already knew my name, branch, links, and project history at the start of tonight's session.
