Current Projects

Skill Builder

A Claude Code skill is a reusable file that tells the AI how to handle a specific task without re-explaining it each session. I built two skills: one that reconciles weekly supplier data into a procurement brief, and one that applies Anthropic's official brand colors to any document. Both are installed and working — a single slash command produces a finished output.

Skills Showcase Landing Page

A landing page for an Atlantis University event on deploying AI agents in real production environments, covering orchestration, evaluation drift, and human handoff. I wrote three progressively detailed prompts for Lovable, an AI web builder, to construct the hero section, speaker profile, and a working registration form step by step. The result is a complete, mobile-responsive page built entirely through prompts, with no code written by hand.

More Memory

A web page and Claude skill that captures notes and decisions from AI conversations and saves them into a structured Notion database so nothing is lost when the chat closes. I built the page, configured the Notion API connection, and wrote the skill so that saved items are tagged by type and organized automatically. The result is a memory layer that grows each session and can be recalled in any future conversation.

Capstone: Local AI for Home Assistant

A home AI system that runs entirely on local hardware — voice commands, camera analysis, and device control, with all data staying on the home network and nothing sent to the cloud. The design connects a local language model, Frigate for camera analysis, Home Assistant for device control, and a local voice interface into one system you can give spoken orders to. The project is in active development; the architecture is defined and components are being integrated.
