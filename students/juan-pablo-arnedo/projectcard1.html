Skill Builder

Building reusable AI tools that handle a task the same way every time, without re-explaining the rules from scratch.

What it is

A Claude Code skill is a short file — written in plain text — that tells the AI exactly how to approach a specific, recurring task. Instead of re-explaining the same rules in every conversation, you write them once and trigger the skill with a slash command. The AI reads the skill file before responding, so the output follows the same logic and structure every time.

The assignment was to design and build skills that solve a real, repeated business problem — not toy examples, but tools someone would actually use in their work.

What I did

I built two skills from scratch.

Supplier Weekly Brief — This skill processes three inputs that a procurement team collects every week: a delivery spreadsheet (promised vs. actual dates, delays, amounts), a quality-incidents log (what went wrong and what it cost), and the notes from each Zoom call with suppliers. The tricky part is that the same cost often appears in two or three of those sources at once. The skill is designed to identify those overlaps and merge them without counting the same amount twice. The output is a single, decision-ready brief the committee can act on in a few minutes.

Anthropic Brand Guidelines — This skill reads a document and applies Anthropic's official visual identity: the correct brand colors (dark ink, red accent, blue secondary) and the correct typefaces (Poppins for headings, Lora for body text). It handles the case where custom fonts are not installed by falling back to standard system fonts gracefully, so the output is always usable.

What came out

Two working skill files, each with a SKILL.md that Claude Code can read and execute immediately. The Supplier Weekly Brief processes a full week of supplier data in seconds and produces a structured report covering delivery performance, cost exposure, open commitments, and decisions needed. The Brand Guidelines skill styles any document to Anthropic's identity without requiring any design knowledge from the person using it.

Both skills are installed and in active use.
