Learning version control with Git & GitHub

I created my own branch to make changes safely, saved my work as commits with short messages, and pushed those commits up to GitHub. Partway through, I created a new branch just before other work was merged into the shared project, so I learned to check for the latest version first and rebuilt the branch from it. I now understand the difference between a branch, a version of the project I can work on, and a folder, where my files actually live.
