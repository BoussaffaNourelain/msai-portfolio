Fuzzy Control Applied to Front Anti-Collision Systems and Automotive Electronic Brakeforce Distribution

This is a university paper that simulated a car safety system combining forward-collision braking with per-wheel brake distribution, using fuzzy logic instead of fixed rules. I helped build the fuzzy logic model and its MATLAB/Simulink simulation, which reads speed, distance, and each tire's grip to decide how hard to brake each wheel. Across several test cases, including emergency stops and uneven road grip, the simulated braking behaved the way a real system would be expected to.
