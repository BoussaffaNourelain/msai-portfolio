Combline-Type Filter and Diplexer Design Report

This is a technical report on designing radio-frequency cavity filters and a diplexer for two nearby radio frequencies, meant to replace a costlier existing design. I used MATLAB to calculate the filter's design values and HFSS simulation software to build, tune, and test the physical cavity and resonator shapes, including a smaller zigzag-shaped version. The resulting filters met the target performance for both frequencies and were combined into a working diplexer design.
