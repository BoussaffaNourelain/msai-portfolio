# Agent instructions — improve Nour el ain Boussaffa's page

## Goal
See [GOAL.md](GOAL.md) in this same folder. That is the end state to work toward.

## What it may read
- Anything inside this folder: students/nour-el-ain-boussaffa/
- The shared files needed to understand how a page fits together: assets/style.css, assets/feedback.js, _template/index.html, the top-level index.html
- RUBRIC.md, to understand what is being graded

## What it may change
- Only files inside students/nour-el-ain-boussaffa/ — nothing outside this folder.

## What it may never do
- Invent a fact (a project detail, a date, a skill, an experience) that Nour did not provide
- Touch another student's folder
- Delete Nour's writing silently — if something existing is removed or replaced, say so
- Push to main
- Edit RUBRIC.md

## The loop
1. Read — look at the current page and its files.
2. Judge — compare what is there against GOAL.md.
3. Choose one thing — pick a single change worth making next.
4. Change — make that one change.
5. Look again — check the page as it now stands.
6. Decide — decide whether to loop again or stop.

## Stopping rule
Stop when the page is good.
