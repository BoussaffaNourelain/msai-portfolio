Raspberry Pi 4 + OpenWrt · isolated student security lab

What SentinelPi Is

SentinelPi is a small, self-contained cybersecurity lab built around a Raspberry Pi 4. The Pi is turned into the lab's own security appliance — it routes traffic, separates the lab from any outside network, hands out addresses, watches traffic for suspicious activity, and keeps a record of everything that happens so it can be reviewed later.

Alongside the Pi, the lab includes an authorized "attacker" machine and an intentionally vulnerable "victim" machine. These let you generate realistic attacks in a safe, contained way and then practice noticing, investigating, and responding to them — the same loop a real security team follows, just at a scale you can run on a desk.

A separate monitoring machine collects logs and evidence over time, so the Pi itself doesn't need to hold everything, and so a reviewer or instructor can look back at what was detected and how it was handled.

SentinelPi

The Raspberry Pi 4 running OpenWrt. It acts as gateway, firewall/NAT device, DHCP/DNS service, intrusion detection sensor, and logging point.

Attacker + Victim

An authorized lab VM plays the attacker; an intentionally vulnerable VM plays the victim. Together they produce realistic traffic to detect and investigate.

Monitor + Evidence

A separate monitoring VM stores logs and security data, alongside packet captures, reports, and documentation from each exercise.

In short: it's a hands-on, isolated environment for learning how networks are secured, monitored, attacked (safely), and defended — with every stage producing evidence you can point to afterward.

Safety rule: This project is designed for an isolated educational lab. It should be kept physically and logically separate from any production or organizational network, and attack exercises should only ever be run against systems within the lab itself.
